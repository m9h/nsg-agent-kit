## New facts this probe established

1. **NEMAR has grown: 547 → 552 datasets.** The mirror is live; re-run `scripts/nemar_search.py`
   rather than trusting an old dataset list.
2. **GPU nodes have 40 cores, not 128.** The 128-core figure in earlier notes came from a CPU-tool
   run. Size `number_cores` per tool — do not assume 128 on `PYTORCH_PY_EXPANSE`.
3. **`nrnivmodl` is absent from the GPU tool** but present on CPU. NEURON mechanism compilation
   belongs on `PY_EXPANSE`; a NEURON/GPU hybrid job would need the mechanisms pre-built.
4. **`netpyne 1.0.4.2` is pre-installed on `PY_EXPANSE`** — older than the 1.1.1 the
   `vc2008-netpyne` model is validated against, so that model must `--target`-install its own.
5. `mne` differs between tools (1.5.1 CPU vs 1.6.1 GPU) — pin it if a result depends on it.
